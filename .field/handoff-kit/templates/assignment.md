# DEPRECATED — legacy assignment template

Do not use this file for a new Contract Worker assignment.

New Contract Worker assignments must use:

```text
.field/handoff-kit/templates/assignment-unique-name.md
```

and must be delivered as:

```text
assignment-<unique-name>.md
```

This legacy filename remains only so older Codex/installer references fail toward a clear migration message rather than silently generating ambiguous `assignment.md` files.
